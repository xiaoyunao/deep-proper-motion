扩区验收在新自行结果前冻结。共同 21–23 等 QSO 的 C1 相对 C0 径向 P68 配对下界需 ≥−10%，独立物理观测块至少 3，总共同暗端样本至少 60，两个新区域均需有支持。零点正式目标仍为每轴 ±0.5 mas/yr。对共享 CCD/field 与处理接缝需要真实留出检验和共同连通支撑。达不到条件时，保存科学结果与停止原因，并明确有限样本或覆盖限制。 [v0.9 计划与验收](docs/v09_completed_plan.md)

## 冻结的新增普通区

- 北内侧 RA 349°–351°、Dec +1°–+3°，几何时间支持 97.5%，实查 491 个 21–23 等光谱 QSO 为准，其中 203 个在 22–23 等。代表邻近重复带的典型单扫描位置。
- 北外侧 RA 351°–353°、Dec +3°–+5°，时间支持 91.75%，425／166 个光谱 QSO。几何抽样无两年以上 SDSS 重复。
- 东南侧 RA 353°–355°、Dec −5°–−3°，时间支持 90.0%，327／125 个光谱 QSO。与两个新增北区的抽样扫描交集均为 0，另有部分 NSC 高密曝光。取数分为四个 1°×1° 分片。

两个纯单扫描区为必要独立对照，北内侧用于验证邻近重复带的适用性。已记录旧场与新区 SDSS 图重叠。真正独立的块数在取数后由实际检测和共享曝光确定。光谱数是取数前的位置机会。 [覆盖回执](results/summary/v10_prospective_footprint_summary.json)

TAP 在长分片上再次停滞。按完整取数回执冻结独立保底对照：保留完整北外侧，东南区只取已经完整的两个东侧分片（RA 354°–355°、Dec −5°–−3°）。独立性按实际运行与曝光图，同一东南区的整场和东半区不可重复计数。保底区在查看新增自行前登记。全部分片可用时继续原定三个区域和北部共解。

## v1.0 逐项验收

| 阶段 | 实测结果 |
|---|---|
| 1 Gaia | 以静态 NSC r 锚点先分离暗 Gaia，再传播亮星标签。旧区可信亮星 6,499／6,045，两轴门槛与 75 项本地测试已核验。 |
| 2 C1 | 两区原检测和四组敏感度复算完成。加入早期 SDSS 的观测杠杆、细组参考数、共享误差与回退见汇总。 |
| 3 普通区 | 完整北外侧及东南东半，两区 5.985 平方度，413 个 21–23 等严格 QSO。物理曝光定义为 2 块，合并观测日后为 1 块，低于 3 块门槛。北内侧及东南西半的缓存待目录服务复苏后续取。 |
| 4 共用参考图 | 东南两个相邻处理核心实际共解、共享 50 个观测组。四处真实 SDSS 相邻 field 差值随 C1 扩大，HEALPix 边缘邻域有实测残差，NSC 同曝光 CCD 重叠证据不足。 |
| 5 剩余项 | 两个旧区完成 C3 训练及独立星系、QSO 消融，收益区间跨零。两区独立曝光残差均显示亮度与 seeing 相关散布；无新增色项、空间项或 DCR 修正获准。 |
| 6 暗端选择 | 旧稀疏区 1,234 个 C1 暗端退出皆由形式误差；新区重复诊断，整年留出复现新增多波段暗候选 502/613 与 227/229，记录已知错配区间。 |
| 7 独立暗星 | 核验公开 HST、HSC 与长基线产品。五处试点的 HST 光学中心近邻缺 ≥5 年配对；连续 C 区其他位置有候选机会。当前证据为 QSO 零点和留出位置。 |
| 8 科学决策 | C0 为一般基准，C1 适合继续在重复丰富区验证及普通区试验。共解是可行的，两轴暗端零点、独立块数和实际 field 连续性仍未通过。连续 99.873 平方度与全部共同覆盖暂停。 |
