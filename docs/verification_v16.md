# v1.6 自行零点、同夜协方差与迁移检验

## 冻结与独立区

从 `71e41f8` 建立研究分支。冻结 C 区 91 核心、481945 个全波段解、384234 个旧质量 r 控制与原共同 C0。逐分片检查记录 SHA、物理观测组与状态协方差，使用已签名公共历元归属索引。原 384219 个物理质量 r 解用于全区产出基准，384234 个旧质量控制用于逐成员恢复审计。

北二区采用既有 v1.3 几何登记的完整窗口及 72 个实际任务，面积 58.720041 平方度。旧 r-only 科学结果已解封。这个区域独立于 C 的空间和误差开发。此轮全波段在整个预登记窗口运行，四个先导按任务名顺序选择。共用一份北二区 C0 和同样的参考组限制。独立区域先导验收是输入／回执／参考图核验。比较结果不用于决定保留哪些登记核心。

## 零点来源

光谱只在盲目录完成后关联。报告 21–22、22–23 等三个全历元类别。星等为光谱比较 r，类别来自成员定义。控制匹配事先固定同核心、单／多 SDSS run 类别、天距 0.5 度、星等差 0.20、SDSS g−i 差 0.50、log(1+NSC 跨度) 差 0.70、联合跨度差 2 年、最大组杠杆差 0.20、形态差 0.20。使用最大可配对数的一对一匹配，并列出忽略颜色这一敏感性对照和其余条件的样本损失。差值区间按对象对重采样，区域系统误差仍由共享观测组与地理重复限制。

追加 r 锚点的 r 子集拟合只使用同一全波段源的实际 r 检测，并记录时间不足、形式误差和标准化位置残差的退出。能数学拟合但未达时间门槛者保留作解释用对照。原控制退出另按物理成员复算原盲关联与选择漏斗。比较查验归属变动、竞争检测和原始质量位，不用自行相近认同源。

## 夜相关误差的可识别性

采用冻结 C0 留出星系。对同一仪器和无序滤光片对，匹配同一星系在同夜不同曝光、30 天内跨夜不同曝光的差分。参考方差使用同步抽样的实际差值，并单列发布质心方差。两个星系子集从原 C0 留出按固定身份哈希产生。方差差的一半只有在剩余边际误差相等时才能解释为公共夜项。差分还含有形态、不同曝光、PSF 和未建模偏移。

一个仪器通用的最小同夜公共项需要在有支持的同色和跨色组合中方向一致，两组原 C0 留出星系均有可复现的正差，并能在固定 QSO 与留出年上改善分条件覆盖。每个差分单元至少报告实际星系和夜数。先行查看单独样本的差分可用于衡量可行性，模型资格判断使用同星系成对的差分。按同夜一侧分块的区间用于组依赖敏感性说明。跨夜一侧可能继续共享曝光。支持不足或差分方向不统一时继续使用 W0，避免把总误差缩放强加到不同扫描条件。

## 真实时间与新增源

复用冻结 A/B/C/B1，S 只添加与原 r 无共同观测季的 NSC 夜（在同一全波段时间序列上采用 90 天间隔）。B 再加原 r 季中的其他夜，C 再加原 r 夜的合格检测。逐 band 删除仍使用同一有覆盖源。位置预测采用原本独立的留出全年关联前隔离。

北二区固定先导与 C 代表区返回真实测试年、CCD 机会、唯一留出重现、位移负对照与光谱成员。全历元非 r 样本以唯一完整 SDSS 检测集合和至少一条共同 NSC 训练测量与年度训练结果连接。全历元类别事后确定，独立测试时未提供此信息。保留无法精确匹配与混叠未知的分母。位置重现与可靠暗星身份是不同证据。

## 复现入口

所有涉及逐检测或逐源的命令在 Slurm 节点及私人 PScratch 版本目录中运行。实际驱动、回执、日志及失败状态与运行版本一起保存。

- `nsc_transfer_audit` 校验 C 冻结目录，`nsc_source_zero` 做光谱源匹配与 r 子集，`nsc_control_exits` 跟踪物理成员与选择路径。
- `nsc_night_pairs` 复用原 C0 留出星系与已签名参考图，`nsc_information qso|year --season` 补充原 ABC/B1 的季节层。
- `nsc_allband_inputs` 与 `nsc_science_catalogue` 在北二区 72 核心执行真实测量取数、拟合和同源比较。以 `nsc_transfer_footprint` 计算共同参考支持下的几何时间机会。
- `allband_blind_year`、`allband_member_audit` 与 `nsc_full_year_identity` 核验已登记先导。完整转移汇总由 `nsc_science_summary` 完成。
- 全部聚合输出经过 `check_aggregate`，图可由 `nsc_transfer_figures` 重现。精确 PScratch 和作业路径保存在私人配置。暗 Gaia 自行继续退出模型选择与验收。
