# v1.3 最终保留窗：方法、评估与生产判断冻结

此决定在读取north_two的自行、残差、留出预测或W0产出指标之前登记。开发依据为冻结C区及已打开的A/B/北一/北三；保留窗从纯几何选区开始一直隔离。输入覆盖、参考支持及作业状态可用于取数调度，不作为自行表现的替代指标。

## 采用方法

只采用C0/M3、W0 r-only、J2015.5四参数稳健自行。保持已登记的参考选择、NSC对象身份仅用于参考及检索、物理组零点、原生误差门槛、50mas各轴底噪、48次参考bootstrap、12mas组误差门槛、1角秒静态候选及W0质量条件。实际定义以[方法审计](method_audit_v13.md)和配置为准；非有限形态未单独拒绝的历史行为明确保留，不把W0总数解释为已确认恒星数。

误差重标定W2与多波段试验没有跨区域稳定收益，额外源有光谱零点偏移，因此不进入最终采用模型。颜色、星等、DCR、CCD或field均值修正未采用。支持掩码的哈希查询优化只改变运行开销，真实目录与科学统计逐值复现已通过；不将提速算作科学收益。

全状态逆投影Jacobian给出每源ICRS运动及4×4协方差，保留独立和参考误差来源。原始位置误差的切平面近似、缺少原生相关系数及跨独立参考图协方差的限制继续声明。不同图的bootstrap索引不能直接当作同步物理抽样。

## 如何作出生产决定

生产判断同时看普通区暗源的精度、尾部、误差可靠性、经验证的有效源数，以及参考系能否给出可用的区域质量等级，不预先要求统一改善某个倍数。相对NSC的大幅改善与相对Xiao的增量分别陈述；重复区收益不能自动外推单扫描区。

若独立窗口与保留窗支持可复现的普通区收益，或支持经过验证的误差／有效源数收益，且共享物理组与跨区结果允许明确的质量分类，则按冻结方法和等级启动全有效覆盖的分批正式计算。先登记覆盖、资源、回执和首批科学核验，再继续下一批。模型参数不因保留窗表现而回调。

若主要收益限于重复扫描，必须明确区域性适用条件。可以根据真实证据选择具有质量等级的分区产品；普通区缺乏可验证增量时，不把处理更多面积本身作为正式广域生产的理由。

若跨区参考、误差可靠性或暗源验证尚不足，则保留研究版本，并说明最小后续校准／质量工作。每轴0.5mas/yr仍是高精度空间零点目标，只在足够统计支持的尺度认证；模型均值区间落入目标并不单独构成空间认证。未达该目标的区域应有相应等级及系统误差限制，不能套用统一高精度标签。

样本或独立观测块不足时，给出当前结果和未知范围，不解释为物理方法已失败。是否进入小规模图像对照，应由具体位置残差与观测条件证据决定；本轮不自动开展大规模DR11 PSF重处理或高自行专项。

## 解封与可追溯性

只有此决定提交并固定后，才生成解封JSON回执。回执绑定最终选区、协议、精度／产出配置、全部Python方法源码、决策文档SHA及C0-only采用状态。默认汇总和几何审核在任何结果文件访问前隔离north_two；显式release验证后才纳入最终测试。

解封后保留原结果，不把测试窗转换为调参集。若发现验证或数据错误，先记录错误与影响，修复结果要说明原测试已被查看，不能称作新的盲测成功。正式产物所需字段及当前缺项见[质量元数据](quality_metadata_v13.md)。
