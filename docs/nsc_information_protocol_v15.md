# v1.5 冻结控制与信息分解

SDSS每物理run只使用发布r位置，全部真实独立run保留；其他band只颜色／光度／DCR。NSC按原生位置／误差／时间、SNR、标志、曝光唯一性与参考支持选择所有实际band，不设固定名字白名单。

## 固定ABC

从v1.4已保存的QSO物理成员及整年先隔离的盲训练r既有成员开始；不按新结果选源。不改变SDSS检测及原r成员。A=SDSSr+NSCr；B=A+原NSCr夜之外的其他band全部合格测量；C=B+原NSCr夜的其他band。A和C分别逐值重现v1.4的r与multi，自行和误差均需通过。

B本身可能在新夜内含多个质心，不能把A→B解释为纯时间因果。补B1：每新增夜仅最早物理曝光，时间／曝光ID／检测ID排序，不按拟合结果或最小误差挑选。B1→B量化新增夜内重复信息；B→C量化原r夜追加信息。逐band删组和真实观测组元数据另报。

夜使用UTC 18时边界；观测季按C统一的90天间隔分段后再对子集计数，避免每个模型自己分组产生不可比的“季”。同时报告两轴W0条件斜率信息、最大物理组／夜贡献和参数的独立／参考协方差；对角权重信息不是已认证的独立夜数。

固定QSO统计全部同源，正式形式误差筛选数量单列，不通过删成功样本获得精度收益。年度比较使用同一冻结训练源与同一C0门限内留出检测，不重新用测试年识别轨迹；位置统计不冒充暗星真实自行。

## 小区完整曝光路线

固定核心几何中心0.05×0.05度切平面小方格；官方chip多边形只要与区域相交就纳入，不要求覆盖中心。分别0.60／1.20度metadata余量检验相交物理chip集合稳定。全部实际曝光／CCD逐一COUNT和返回行数核验、可恢复缓存，所有band保留，不选首末曝光或TOP样本。

与原输入比较精确measid；只在同一几何／曝光／CCD机会集合比较旧已返回检测，缺一条即报错。记录缺少r的原object索引标签仅用于获取审计，不作新盲源身份或完备性真值。metadata边界稳定证明的是该官方检索条件下的目录覆盖，不能声称图像提取完整。小区验证成功后才扩大取数。

## 后续模型与连续试运行

旧共同参考、g经验色项及所有负结果冻结。新DCR仅一个有真实观测几何的剩余项，必须核查发布WCS已有处理，独立参考训练、留出星系/QSO/盲新增/年度评价，并传播颜色误差；不按QSO偏差调系数。W0不变，旧误差参数不直接采用。

连续约100平方度是科研试运行，冻结实际测量与参考支持后以最小正确模型开展，完整标记无支持、条件零点和源身份限制；它与正式高精度产品验收分开。不得因正式全覆盖门槛未通过而把本轮科研试运行直接取消，也不能把其面积或候选数当认证星表。
