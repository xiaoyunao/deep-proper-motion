# v0.8 区域科学验证

输入为 SDSS DR17 和 NSC DR2 已发布逐曝光目录。科学试运行用已有的 22.082 平方度作历史对照，v0.8 新区独立查看。目标约 100 平方度。W0 采用固定 1″ 的普通源关联、M3 星系参考和 r 波段稳健四参数拟合。另保持相同锚点的 W1 r 和 W1 加已校准的 NSC g/i/z。参见 [v0.7 报告](../reports/experiment_A_v0.7_regional.md)。

## 冻结与计算

候选核心为 0.785° 半径圆盘，与既有试验及其他候选分开。几何预查采样 SDSS 独立物理 run 和 NSC r 芯片足迹。保留双覆盖率至少 0.72、合格的 NSC r 时间跨度（≥0.60 年）面积比例至少 0.55、至少八个有双巡天地理机会的 r=21–23 光谱 QSO、核心档案对象至少一千个，且缓冲内最多 85,000 个档案对象。名称、覆盖率、芯片数量和档案规模均以候选收据为准。选区优先增加物理 SDSS run 和覆盖条件多样性。预计每批 11 核心，约 21.3 平方度，先处理第一批。QSO 和 Gaia 的运动只用于求解后的评估。

节点按 Slurm task rank 分配，节点内用有限个独立 Python worker，每个 worker 的 BLAS 限一个线程。以数据量和各场实测内存、时间记录判断下一批资源，重试在原版本根下使用带行数和摘要校验的分片缓存。每批检查实际双覆盖、W0/W1 与多波段检测数、同源对照、零点及耗时。科学偏差场继续留在统计中，并加上质量标志。

## 统计口径

- 用严格共同的光谱 QSO 对比 W0 和官方 NSC，采用二维绝对自行误差的 68% 分位数、两轴中位零点、每轴尾部及形式误差覆盖率。Gaia DR3 检验恒星和可分辨的关联成员。NSC 的既有 Gaia DR2 标定是共有基础。
- 每个核心的对象重抽样给出场内条件区间。合并时，同一个 SDSS 物理 run 或 NSC 曝光连接的区域并为一个块。先重抽观测块，再重抽块内共同对象。合并区间只有在覆盖至少三个含有资格样本的物理块时可用于高精度认定。保留每轴 ±0.5 mas/yr 目标及 v0.7 场级门槛，包括已知错误成员、暗端产出和精度收益。报告样本量、区间半宽、区间排除零和区间完全在目标阈值外。这些条件分别解释统计支持、检测到的偏差和科学目标。检查空间偏差的同时考虑多个切片，不把任一边缘显著切片当作方法优劣的证据。
- 比较历史相邻星等带时先固定天区、主时间杠杆的 SDSS run/camcol、NSC 主仪器、NSC r 时间跨度是否超过两年及观测中位年是否早于 2017。每一层的每个星等带至少三个 QSO，先计算中位零点差，再给观测块相同权重。另对有独立 g−i 的对象同时匹配颜色档位。
- 仅调整 CLASS_STAR 门槛作消融，主设定仍为 0.8。使用 DESI 光谱 QSO 和 Gaia 样本分别追踪星等、seeing 和最近邻距离。已知标签可给成员错误下限，无法标记的检测仍未知。线性空间残差梯度只用训练星系估计，独立星系和 QSO 分别检验。采取修正须有独立重复收益。
- 整年留出在关联和拟合前去掉测试年恒星检测。比较同一测试检测和共同 r 锚点，另报告多波段独有候选。由芯片多边形估计几何机会，附近的已发布且通过质量切选的 r 测量另计。几何覆盖不包含通量、坏像元、混叠或检测完整度。留出重现评估位置预测的一致性，暗星绝对自行精度需要外部星历。
