# 广域科研生产与质量回执

从 v1.6 `992c9f1` 冻结数学和质量选择。SDSS 的独立物理 run 使用发布 r 质心，查找输入重复须按真实检测身份。NSC 对象仅作检索索引。NSC 全波段取数、星系 C0、50 mas 对角权重、同步 bootstrap、J2015.5 ICRS 状态及 4×4 条件协方差用原验证流程。冻结 C 和北二区是生产对照，扩参考图时旧结果独立留存。

## 数据和参考

- 旧缓存分片用 `nsc_allband_inputs` 补齐。原 r 输入、目标几何与回执绑定，逐检测检查旧 SDSS r 和 NSC 的位置、误差、时标及 photometry。原始私有文件只留 PScratch。
- 新天区使用 `independent_batch` 生成分片。如总配置包含 `nsc_all_objects = true`，则 `exposure_inputs` 直接获取可检索的全部 NSC 对象测量，避免下载两遍再取消 r 索引限制。数据版本、COUNT 及备份查询仍以回执核验。
- 原参考身份/split 与固定质心保留。共享组被发现跨窗口时，`joint_reference` 重投影实际参考，`continuous_reference solve --separate-components` 一次联合求解。记原投影、共同图支持数、分量和拒绝数。W0 的原生位置误差切平面近似保持不变。每个生产分片保留实际图 SHA 与拟合时使用的参考分量。
- 初始 A/B 原图共享 1 个保留组，北一／北三共享 131 个，北一／北二区 8 个，北三／北二区 3 个。北二区重放可用于保持新一版账本一致，面积与原北二区并集只计一次。现有 C 区冻结对照单独核对物理组重叠。

## 科学产品

广域拟合通过 `nsc_science_catalogue`，归属按拟合 J2015.5 的位置。归属变更用签名索引保留原状态、协方差、成员及回执。HEALPix NSIDE=128 用于存储索引与质量分区；参考求解覆盖实际相连的校准观测。每批记录重复检查、跨核物理成员共享和未获参考支持的区。

新增质量标识只在广域配置置 `production_quality_tags = true` 后启用。无 NSC r 锚点独立列出。某个物理组在任一轴占至少 80% 的条件斜率信息则标高杠杆。各核心参加投票的参考分量计数保留，用于说明同一核心可能有少用参考数据。原未知空间系统、夜相关与暗星身份质量标志继续保留。

`nsc_science_summary` 按相同光谱源分别给物理 r 和全 NSC，外部再比较 Xiao2025 的 DESI 来源及官方 DR2。绝对 P68、NMAD、误差覆盖、两轴零点、来源类和时基保留。位置唯一匹配提供条件身份信息。独立年位置使用全部 band 先隔离测试年。暗端 Gaia 自行退出验收。

名义面积、带参考支持的几何时基及实际科研解覆盖分列。`nsc_transfer_footprint` 按实际每核心参考分量读 CCD 多边形、原生 SDSS 扫描和真实时刻。几何条件沿用至少一次 SDSS、两次 NSC、NSC 跨度 0.60 年以上、联合跨度 5 年以上。几何机会面积独立于逐源深度、源提取、配对和正式空间零点认证。

全部作业在 Slurm CPU 节点运行。原始、逐源、私人星系和光谱证据保持在 PScratch。每批从明确允许列表同步聚合统计、图和研究记录。
