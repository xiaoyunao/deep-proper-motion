# Stripe 82 共同恒星比较

在读取任何跨目录自行差值前冻结以下规则。输入为 V/141 中八个完整 HLC FITS，各区行数与 ReadMe 相符。原 FITS 自行是 arcsec/yr，精简 ASCII 表则是 mas/yr；使用原 FITS 的 clipped 解。RA_PM_CLIP 已是东向分量，传播 RA 时按源纬度除一次余弦。T0_CLIP 是每源加权 HJD，使用论文位置模型传播到 J2015.5。HJD 与共同历元的分钟级光行时差远小于普通源目录位置误差。[作者的定义，式 3–5 与表 5](https://lss.fnal.gov/archive/2008/pub/fermilab-pub-08-399-cd.pdf) · [完整 HLC](https://vizier.cfa.harvard.edu/ftp/cats/V/141/hlc/)

恒星母样本采用 MEAN_OBJECT_TYPE≥5.5、16≤clipped PSF r<24、r 合格历元≥5、0<r 星等误差≤0.15、clipped 位置历元≥10、原始跨度≥730.5天、双轴 PM 误差在 (0,20] mas/yr、每轴 clipped 线性模型 χ²/(N−2) 在 [0,5]，并要求解和历元有限。以同一个 HLC r 定义所有目录的星等档；g−i 仅用于有光度支持的颜色分层。保留候选、光度形态、天测、几何及严格交集的分母。

两目录均在 J2015.5 用单位矢量检索。选择相互最近且球面距离≤0.7″、两方向次近竞争差均≥0.3″。HLC 中有可用位置的竞争源保留，缺运动时用发布位置并标记。邻源、颜色、星等、SDSS 独立 run/年及时基在已冻结身份后分层，不按运动一致性或运动显著性选样。机会范围使用相同版本几何；成员数不足的档仍保留计数。报告两轴中位与 NMAD、差值矢量 P68、径向>20 mas/yr 尾及物理组重权敏感性。20 个以上共同对象可描述一档的散布，仍须报告 N/区间；深度与测量代表性分开。

三路严格共同是新目录、官方 NSC 与 Xiao 地基条目均唯一对应到同一 HLC 恒星。分别保留相对同一 HLC 母样本的匹配率。Xiao 使用实际 DESI 历元、NSC 使用实际 mean MJD，缺历元单列。S82 共享 SDSS 观测，差值协方差包含两个负的交叉协方差项；仅在真实逐 run 信息支持时解释独立误差。按天区/观测条件量化差值，单/多 run 比较用于时间信息解释。
