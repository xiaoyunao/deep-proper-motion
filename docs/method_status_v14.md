# v1.4 实际启用状态与误差定义

本审计描述实际运行代码，不把计划中的修正当已开启。冻结参照仍为5fba219的C0/M3、W0 r-only、J2015.5、四参数稳健自行；旧C1/C1b负结果和v1.2/v1.3回执保持。新增模型全部是研究对照，未获生产采用。

| 项目 | 冻结C0及本轮实际操作 | 未通过／未启用 |
|---|---|---|
| 静止参考与身份 | 原训练／留出参考按物理源隔离，N1/N3以相同检测和split hash重投影共同求解；候选参考重复按物理观测核验 | 不把NSC objectid当恒星盲关联真值；未强行连接独立规范或用恒星均值设零 |
| 物理零点 | SDSS run/camcol、NSC exposure自由二维偏移；共同图保留1436组、两个规范 | 无额外不可辨识的全band常数；CCD／field／像面位置没有默认独立校正 |
| 权重 | W0两轴原生误差分别平方加50mas，再进入稳健拟合；native RAERR已含cos，不重复乘 | 未默认令两轴或两巡天误差相同；没有把经验W2或更小floor自动采用 |
| 参考不确定度 | 同一次物理参考bootstrap同步作用各组，传播源完整4×4参数协方差，再到ICRS | 不同独立旧图的draw序号不假装配对；公共误差不按源数缩小 |
| A支持敏感性 | 原1726组逐值复现；另复制全部1938组pre-SE点值及完整draw，212组SE退出主要公共平移 | 没有删掉共同位置模式后把内部约1mas当绝对误差；不是已采用的支持恢复方案 |
| 时间与运动 | 实际观测时间转换为TT年，r参考波段与时间核对；四参数位置＋线性两分量、稳健权重、J2015.5 | 不把J2000坐标当2000年曝光；同夜多band不当独立长期历元；未使用暗Gaia PM／视差 |
| 全NSC band候选 | 所有实际band按合法坐标／时间／两轴误差、SNR≥5、致命标志、参考支持与物理重复检查，有形态控制但不要求每次严格点源 | band名不是白名单；u／Y／VR也受相同资格化，缺支持不强行采用；旧r对象获取选择仍限制检索完备性 |
| 关联及异常 | 常规位置锚点／竞争门限保持，固定对象与重新盲发现分开；稳健拟合和既有形式误差／归属／残差筛选 | 当前不是高自行专项；最小残差或测试年近邻重现不自动认定同源／正确自行 |
| 误差试验C | 独立星系同夜／跨夜重复对学习scale、独立floor、夜项；显式GLS与共享参考协方差 | 参数学习误差、跨band夜相关、完整原生跨轴项尚未认证，跨区QSO无一致收益，不采用 |
| 经验颜色项 | 有独立星系信号后，仅主分量DECam g的一项二维(g-i−1.2)，与组零点／静止位置联合求解；同步组／色项draw先加再传播 | 不称已识别DCR；缺颜色显式未校准域，颜色测量误差尚未资格化；QSO未训练系数，新增QSO零点未改善，未采用 |
| DCR／光行差 | 发布目录已有天测与SDSS光学／DCR标定，只检查剩余条件残差；真实WCS重建使用发布参数核对 | 不把地面观测再次加一次完整光行差／已有DCR；无独立观测几何收益，不加新的几何DCR、seeing或星等修正 |
| SDSS其他band D | 实物核对offset、5维TAI、逐band像素质心和WCS二维误差；r发布误差实测约等于质心项，场级MUERR/NUERR另列 | 非r标志、独立对象预测、颜色及同scan跨band共享协方差未通过；未进入D拟合，不复制r误差五次 |
| 标准输出 | 切平面状态经每源坐标Jacobian转ICRS (mu_alpha*,mu_delta)，包括位置－自行交叉项和4×4协方差 | 机械共享图同检测零差不等于独立空间零点认证；研究产品不是正式发布星表 |

主要源码：`continuous_reference.py`／`zero_point.py`共同图，`precision_v03.py`／`astrometry.py`／`standard_motion.py`权重与状态传播，`allband_qso.py`固定源，`allband_blind_year.py`训练年度先隔离，`allband_member_audit.py`身份审计，`correlated_motion.py`／`multiband_error_trial.py`误差试验，`chromatic_reference.py`／`chromatic_validation.py`独立色项与固定盲源评估，`sdss_band_probe.py`／`sdss_position_check.py`真实FITS核查。

复现入口参见[协议](allband_protocol_v14.md)。原生误差投影近似、颜色误差及未建模的空间／夜共模需与正式协方差字段分开列为限制。当前不能给出已认证可信暗星数量或全区高精度质量等级。
