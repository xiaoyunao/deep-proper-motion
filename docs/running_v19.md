# v1.9 生产范围与运行记录

从 `a8938ea` 继续。以 2,251 核心、2,154.184 名义平方度为冻结目录。新增窗口先以实际 SDSS field、NSC CCD 足迹、历元、仪器、候选共同物理组及光谱 QSO 位置登记，随后才读取新增自行。任务规划范围为 500–1000 平方度，约 800 为起点。

## 批次与恢复

- `production_geometry` 通过 SDSS DR17 档案与 NSC DR2 CCD 足迹选取 2° 单元，按实际时间戳估计几何机会。以可能物理组与冻结参考域的交集估计旧域重放。
- `production_registration` 在完整窗口组合里根据面积、时间支持、预计数据量和旧域重放成本登记。回执绑定原目录、几何快照、光谱坐标及配置的 SHA256。
- `scripts/wide-v19-production.sh` 先在 Slurm 做代表核心取数和参考星系提取，核对实际行数、检测和参考回执及预算。第一段通过后继续已登记范围。按真实训练星系的物理组确定共同参考图闭合。参考求解保留原 C0、48 次同步抽样及可恢复断点。
- 拟合继续使用原 SDSS r、全部合格 NSC 单曝光和 W0，保存标准 J2015.5 ICRS 自行、4×4 条件协方差及真实成员。最终归属核对新、重放和复用核心，光谱验证在盲产出冻结后进行。

## 资源

启动前核实 `desi` CPU 剩余额度约 452.5 节点小时。PScratch 使用 10.53／20 TiB、约 431 万／1000 万 inode。主任务规划上限为 48 计费节点小时，小任务合计保留约 2 小时。预计峰值增量以 1 TiB 规划。实际资源由 Slurm 分配、QOS 和有效时间结算。 [NERSC QOS](https://docs.nersc.gov/jobs/policy/)
