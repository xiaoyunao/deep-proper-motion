# 实验 A v1.0 · C1 适用范围与连续参考系

本轮沿用 v0.9 的 SDSS+NSC 单次检测、参考星系划分与 C0／C1。C0 校准到 SDSS run×camcol 和 NSC exposure，C1 细到 SDSS field、NSC CCD，并在同一解中对支持薄弱的组回退。主要问题是 C1 在普通扫描条件下能否提高自行，以及物理探测器和跨分块能否使用同一个参考系。 [v0.9 报告](experiment_A_v0.9_exposure.md) · [八项方案](../PLAN.md)

## 验证协议

可信 Gaia 恒星须同时满足 NSC r<21、Gaia G<20、两轴自行误差<0.5 mas/yr、RUWE<1.4、至少 9 个可见期以及有效五或六参数解。沿用 |视差|<10 mas 的验证传播范围。先用 Gaia 参考位置与盲生成的 NSC r 锚点在 1″ 内唯一匹配，候选间距优势至少 0.3″。只传播通过亮度和观测质量门槛的 Gaia 自行。最后再按用于评估的 NSC r 重验亮度。历史 r≥21 Gaia 样本只计数，绝对零点和方法判定使用独立光谱 QSO、整年留出位置与可核验的暗恒星外部天测。NSC 使用 Gaia DR2 标定参考框架，亮星验证中的独立性指目标参考自行在关联和拟合中隔离。

严格比较对相同天体使用相同支持检测。对暗端 QSO，以共享的 SDSS run 或 NSC 曝光连出观测块，并以加上 NSC 观测夜的连接作保守对照。扩区阈值在新自行结果前冻结。暗端严格共同数至少 60、至少 3 个独立块、两个新区域均有支持，C1 的 QSO 自行 P68 改善 95% 下界至少 −10%。正式零点目标仍为每轴 ±0.5 mas/yr。观测组和处理块连续性另需真实独立边界证据。

## 暗恒星外部参照

Fajardo-Acosta 等的 HST ACS＋Subaru HSC 结果覆盖 COSMOS，样本到 i=25，早晚相差约 11 年，参考格由传播后的 Gaia DR2 校准。该场在本轮冻结 C 区域之外。Subaru HSC＋SDSS Stripe 82 的公开研究与本区部分重叠，但使用同一巡天早期位置。其对照可帮助判断相对表现，独立性低于 HST＋Subaru。HST HACKS 发布星团内部运动与摄影天测，须按具体目标、参考零点和重合检测审核后才能用于绝对精度。 [COSMOS 研究](https://authors.library.caltech.edu/records/8qtqw-50k24) · [HSC＋SDSS 研究](https://academic.oup.com/mnras/article/501/4/5149/6054531) · [HACKS 发布](https://archive.stsci.edu/hlsp/hacks)

已实查 [STScI CAOM TAP](https://mast.stsci.edu/vo-tap/api/v0.1/caom/) 的 HST 图像观测中心。连续 C 区有 3,154 个去重后的 ACS/WFC、WFC3/UVIS 或 WFPC2/WFC 观测 ID，其中 590 个有距离不超过 72″ 且相隔至少五年的中心配对。逐一限制到两个旧试点和三个新增区域内部时，五区的长基线候选配对均为 0。这是中心和时间的初筛，无法代替图像足迹或逐源自行。已核验的公开产品在这五区未提供可直接使用的独立暗恒星绝对自行。后续可在整个 C 区内的 590 个潜在曝光观测 ID 上优先检查足迹、通带、参考格和现有星表。当前暗端验证依赖 QSO 与整年位置留出。 [HSC v4 天测文档](https://outerspace.stsci.edu/spaces/HSC/pages/421462929/HSCv4%2BAstrometry)

## 原稀疏试点复核

### 暗端退出原因

初始 2,770 个 22–23 等 r 锚点中，1,356 个有足够的校准与时间支持。C0／C1 分别保留 124／122 个。对 C1，1,234 个退出全部属于两轴中最大形式自行误差超过 10 mas/yr，归一化残差阈值单独或共同造成的退出均为 0。

| C1 暗源子样本 | n | 最大轴形式误差中位数（mas/yr） | 联合跨度中位数（年） | NSC 独立曝光中位数 | 最早 SDSS run 杠杆中位比例 |
|---|---:|---:|---:|---:|---:|
| 合格 | 122 | 9.40 | 9.85 | 4 | 41.1% |
| 仅形式误差超限 | 1,234 | 13.51 | 8.99 | 3 | 69.3% |

这两组 NSC 测量 r 中位数分别为 22.09 和 22.24，归一化残差的组中位数分别为 0.62 和 0.54。形式上限放宽到 15／20 mas/yr，可分别达到 932／1,229 个，反映精度与产出的权衡。保留正式 10 mas/yr 阈值，较宽版本的科学用途仍依赖独立位置和污染证据。该场校准后可供共同预测的 NSC r 只有两年，整年留出没有充足的训练年份。

### C1 参数敏感度

在固定的 5,201 个留出星系上，C0 跨巡天位置 P68 为 157.01 mas，C1 原方案为 145.18 mas。参考星系数从 15 改为 10／25 时分别为 144.84／145.64 mas。父组约束由 50 改为 25／100 mas 时分别为 144.29／145.29 mas。改善方向在这些单因素扰动中一致。结果用于检查敏感度，保留冻结设置。

近 HEALPix 边的 1,129 个留出星系中，C0／C1 位置差 P68 为 168.81／159.82 mas。模拟处理接缝两侧 2′ 宽条带内的 153 个跨巡天同源比较为 163.90／171.81 mas。这是同一解内的邻边诊断，两个独立处理块的直接跳变仍需重叠星系和实际共解查验。

## 真实 SDSS field 边界与色项最小试验

从 DR17 SAS 复读相邻 field 的 `photoObj`，先保留 RUN_PRIMARY 去重之前的记录，再以留出星系选取同 run、同 camcol 的重复测量。每场选择留出支持最高的 160 个相邻 field，限制为无子对象、以 r 为坐标参考且唯一的 0.5″ 内匹配。得到真实重复区 549 对（覆盖 34 个 run）、旧稀疏区 316 对（覆盖 5 个 run）。相邻位置差 P68 的 C0／C1 比较分别为 **39.21／61.27 mas** 与 **58.49／74.40 mas**。C0 给同父组重复记录作相同平移，C1 的细组解会改变相邻处理窗口的相对位置。这是一项实际接缝风险。样本的 field 选择偏向能实测的重叠，指标不能外推到遍布天区的全部 field。

在真实星系训练组上估计相对 SDSS–NSC 的一个 g−i 斜率，应用时保留已冻结的 C1 常数零点。两处的北向斜率分别为 −10.71、−14.44 mas/mag。按真实可用颜色范围对比，重复区 7,603 个留出星系的位置 P68 103.49→102.96 mas，旧稀疏区 4,984 个为 151.91→151.49 mas，两场的配对收益区间都跨零。439 个重复区独立 QSO 的自行 P68 2.99→2.97 mas/yr，改善区间 −7.5% 至 +6.0%。旧稀疏区仅 13 个 QSO 具备共同可靠颜色，区间 −13.5% 至 +9.7%。在本轮证据下保留 C1 的原有色项设置。

同一 NSC r 通带内，对每个留出星系逐曝光用其余曝光的中位位置作为参照。重复区和旧稀疏区分别有 98,698 和 16,367 条支持测量。按 FWHM 分成三个近似等数档，C1 位置 P68 分别为 57.4／70.7／82.2 mas 和 71.0／79.2／89.9 mas。按 r 星等的三档分别为 56.5／70.0／81.4 mas 和 63.4／79.5／95.4 mas。两场共同表现为测量散布随星等和图像质量改变。气团分档在两场均未显示单调散布趋势，像面 x/y 分档的中位位置差在约 2 mas 内。该诊断使用发布的正 FWHM、可用气团及有效 g−i，未用天顶方向拟合额外 DCR。 [重复区边界和观测条件](../results/summary/v10_repeat_rich_validation_existing_v10_d8eeaadebff0_f10a8f806cae_summary.json) · [稀疏区边界和观测条件](../results/summary/v10_repeat_sparse_validation_existing_v10_d8eeaadebff0_f10a8f806cae_summary.json)

## 共用参考图与最终决策

将东南东半部真正相邻的 south_se／south_ne 两块按物理检测 ID 合并。在统一切平面和一个 C1 解中，星系与实际观测连接形成 1 个分量。共有 50 个支持的物理组实际用于两块核心，其中 SDSS 7 个、NSC 43 个，跨分片的重复检测去掉 29,583 条。两块分别有 724,293/724,296 和 214,727/214,727 条有效位置获得共同解。相同训练参考图下，各核心留出星系位置 P68 分别为 160.08→153.98 mas（1,299 个）和 148.80→134.36 mas（1,264 个）。这验证了两块共用物理组零点与单一约束的实现。没有留出星系经核心归属判定同时进入两侧，且本轮缺少同时落在相邻 NSC CCD 的有效同曝光重复星系。直接 SDSS field 跳变仍然变大。 [共用参考图](../figures/v10_shared_reference_summary.png) · [共解回执](../results/summary/v10_south_shared_validation_shared_v10_df20a0fd3a8f_3b1d0e0f201a_summary.json)

**本轮保留 C0 为普通生产基准，C1 保留为有独立精度收益的候选。** C1 在重复丰富区、部分普通区和四处的可靠亮星上都显示散布收益。普通区 21–23 等 QSO 的描述性收益为 12.7%，最暗 22–23 等为 2.9%。两个物理块不足以认证普通天区的非劣效，四处实测 SDSS 重叠均提示 C1 的边界代价。联合覆盖范围仍按冻结规则停在试验阶段。后续最有区分力的是给相邻处理窗口加入训练重叠约束，再用独立留出重叠星系检验是否降低跳变，并增加真正独立的 SDSS run／NSC 观测夜。具有较少历元且形式误差较大的暗星可以单独标注精度等级，绝对暗恒星精度等待独立参照补齐。
