## 下一研究的优先级

1. 固定本轮对象及成员，区分C积极结果与B／北一负结果所对应的真实时间／band／仪器条件；已有控制不称新盲区。逐band覆盖数不等于独立精度贡献。
2. 优先检验可辨识的公共位置／参考误差与新增源零点；训练星系、检验星系、QSO和亮端可靠恒星用途分开，不用待验收QSO反调系数，不再扩展已失败的一项DCR或直接沿用旧学习误差。
3. 追踪272条旧控制未恢复的物理成员／竞争／质量退出，并为非r锚点增加独立身份与整年位置证据。全年训练类别不能当全历元类别；Gaia暗端自行继续退出。
4. 在独立观测条件下同时支持可信精度／源数及零点／误差后，再决定分层生产、区域质量等级和源级公共误差元数据。每轴0.5 mas/yr是高精度目标，不能当唯一停止条件。
