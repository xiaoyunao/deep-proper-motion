# 实验 A v1.1 · SDSS 相邻 field 零点约束

以 428f1c5 为基线。首要问题是约束同一扫描的相邻 field 能否保留 C1 的精度增益，同时恢复 C0 的扫描连续性。普通区继续采用 C0，生产范围由本轮验收决定。

## 冻结的门槛

- 每个普通场的相邻 field 径向 P68 至多比 C0 高 5%，至少有 3 个独立 SDSS run 支持区间且按 run 配对重采样的损失上界至多 10%。另外报告配对点数、两轴偏差、P90 和 P95。
- 留出星系跨巡天位置径向 P68 至少保留 C1 相对 C0 点估计增益的 80%。若 C1 无增益，则用 C0 作比较，C1b 至多相对损失 5%。
- 普通区 22≤r<23 的严格三路样本至少 60 个，采用真实共同 SDSS run、NSC exposure/观测日组成的独立块，保守定义至少 3 块。C1b 相对 C1 径向 P68 的提升率 95% 下界至少 −10%，C1b 相对 C0 的点估计收益为正；两分量零点的 95% 区间都在 ±0.5 mas/yr。少于 3 块只报告点估计。盲产出对 C1 下降不得超过 5%。同时报告五路同源子样本和样本损失。
- C1b 重叠项仅作用于 C1 已支持的 SDSS 细组。按源和 run 限定同扫重叠贡献，差分误差包含额外 20 mas 地板，稳健权重和参考源 bootstrap 同时作用于位置与差分。具体配置随结果保存。

### 冻结的额外普通场

复用 v0.8 已取完的 south_17 星表，取 RA 197.30°–198.30°、Dec +3.40°–+4.40° 的内接核心及 0.06° 缓冲。它在覆盖统计的已完成外部普通场中有最多的候选暗光谱 QSO，母区几何联合覆盖为 100%，长间隔 SDSS 重复率为 7.0%。选择基于既有覆盖与光谱位置机会。独立性仍需实查物理曝光、SDSS run 和 NSC 观测日。它不用于选择 C1b 参数。
