# 连续 C 全NSC科研试运行冻结方案

本轮是用户授权的连续约10×10度科研试运行，不能以正式高精度门槛未过为由取消。沿用v1.2原91核心半开归属、99.873平方度、J2015.5、NSIDE128组织，以及**同一份已保存全C物理观测组C0参考图及同步bootstrap**。该参考图原本已用可用NSC各band参考星系，r-only指源测量对照而不是只校准r。本轮主比较不重选参考星系、不独立按小块求零点，从而把新检测信息和参考图变化分开。未支持的真实组保留库存，不为增加源数取消原SE门槛。

## 输入与启动条件

冻结原sources／fits／references清单及图SHA后，取消NSC object的ndetr／rmag／nphotr条件。每个core+halo内以空间索引取全部对象标签，分块COUNT与返回量核验，测量按物理measid去重，逐ID／位置／时刻／误差收回原NSC输入；SDSS使用已保存且签名的r位置、全部物理run，不重新解析质心。早期原始SDSS光度文件未被旧回执签名时，只绑定当前SHA，不声称历史验证；v0.9部分核心原光度文件已不存在，保留已签名r天测位置并显式标记光度不可用，不创建假文件、不影响本轮无新DCR的科学试运行。

先导B已实际收回完整曝光路线757/757检测、新增55725条NSC测量、保留48967条SDSS r，峰值约1.2GiB；普通C先导需另确认。已有quota足以承载预查约30.4GiB reported测量估算，真实下载／标准化／缓存体积另计。宽区object中心和halo仍有选择，不能据小区通过声称图像完备。

## 科研目录与公平对照

- 原r-only结果不覆盖；新输入在同一冻结共同图下保留原质量r控制、物理筛选r控制、全NSC r锚点和无合格NSCr锚点发现。
- 新全NSC检测按原生位置/时刻/误差、SNR、物理标志与共同参考支持选取，不按band名字排除。
- 同一曝光不可被两个输出源使用。非r路线不能包含合格NSCr锚点，r星等来自真实NSCr或SDSSr，未知r星等单列。
- 源发现先冻结再查光谱目标。静止QSO不用来训练零点／误差；暗Gaia自行不读取为验收或选择。已知光谱位置同源与盲输出证据分开。
- QSO比较同时报告固定同源r/full、严格共同NSC／Xiao（PM_SOURCE=DESI）以及盲输出子样本。新物理筛选的损失单列，不把筛选收益归给band。
- 盲源有效数量是研究质量解，不是已认证暗星。全年隔离、机会/成员/位移负对照在预登记代表核心另运行，不能把全历元拟合后的残差称独立预测。

## 误差、空间与决定

保持W0原生每轴误差+50mas和四参数稳健直线。输出每源标准ICRS4×4协方差、独立／参考切平面分量、物理组、band/仪器/曝光、UTC18夜、时间信息及参考图SHA。未知夜相关性与空间零点显式未认证；同步参考bootstrap不按源数缩小。

已失败的唯一g几何DCR与旧星系学习误差不进入采用模型。年度位置覆盖和QSO精度是独立评分；减少形式误差不自动构成收益。保留两暗档／单多run／真实仪器和时基分层、足够样本尺度的QSO零点图及组支持。几何面积、源占据像素、合格曝光足迹面积和认证面积不得互相替代。

实际全区运行、归属／重复／参考一致性和代表年度验证后，才依据可信精度、源数和零点判断正式全覆盖生产。当前不作生产承诺，不调DCR、不开展SDSS五band位置、全量PSF或论文。
