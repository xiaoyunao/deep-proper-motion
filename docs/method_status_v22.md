# v2.2 实际方法与误差定义

本文件描述实际执行的代码，不把尚待全域读出的科学结果写成已通过。旧6faabde目录与75a7abf审阅保持只读；[运行与恢复](running_v22.md)、[私有目录布局](catalogue_layout_v22.md)和[逐项验收](full_coordinate_v22.md)分别登记状态。

## 数据、关联与选择

SDSS每个独立物理run保留发布r天测位置，使用实际观测时刻；其他滤光片只作颜色/光度诊断。NSC所有band按同一物理质量规则进入候选，不按滤光片名字排除。规范输入沿用已核验的TT MJD和原生局部东/北角误差；坐标参考系与真实观测历元分开。

NSC物理选择实际为有限且正的原生两轴误差≤200mas、有限坐标/时间、有效星等及测光误差对应SNR≥5，整数质量flags在0–255内且`flags & 252 == 0`。不是仅凭滤光片或光度SNR认证天测位置。r-only保留legacy-quality与physical-quality两条对照；全band采用后者。现有源提取/WCS与已发布误差的局限没有被这些目录级门槛消除。

普通源使用1arcsec真实球面距离的静态候选关联及曝光唯一性，不是未知高自行轨迹全搜索。跨曝光图/锚点/竞争、参考匹配/隔离/光谱排除与最终身份距离使用球面索引。保留原r锚点形态中位0.8规则；历史缺测/无效形态逻辑未悄悄改成新筛选，有关输出另加标志。非r路线要求合法形态中位≥0.8且不能借用合格NSC r锚点或已保留检测。

合格轨迹至少含一次SDSS和两次NSC检测，NSC时基≥0.60yr、联合时基≥5yr。参考筛除后重新核验时间支持。最大单轴标准ICRS自行形式误差≤10mas/yr，二维标准化残差模的P68≤3；稳健拟合对异常测量降权，未以删点扩大好看样本。只有两个长期时间组的歧义不因曝光多而消失。

`r_existing`是与**本轮legacy-r控制**成员至少60%连续的全band源，`extra_r_anchor`是在同轮扩band后通过的其他r锚点源，`non_r_anchor`为无合格NSC r锚点的独立路线。它们不是与旧6faabde目录逐源连续性的替代；跨版本精确成员/双向唯一成员连接另算。全band源数净增对physical-r采用同一origin阶段分母，不拿origin r数与全局accepted数相减。

## 参考星系与公共参考系

实际`reference_rows`沿用本项目冻结定义，**不是逐字复制Xiao2025的DESI星等筛选**：NSC已有对象标签作参考检索身份，测量星等15–23、NSC r形态中位≤0.85；NSC位置代表要求相邻参考候选≥1.2arcsec、离Gaia/光谱排除位置>1.5arcsec。SDSS要求TYPE=3、nchild=0、16≤r≤22、0≤magerr≤0.15，并在0.5arcsec内关联。每参考/物理曝光的重复检测全部退出该参考入口。SDSS星系条件与排除/隔离共同支持背景源选择，形态值本身不保证纯静止星系。

同一物理参考身份的hash决定30%留出，所有检测共同进入训练或验证；新增参考仍用原hash。全域先按真实检测身份去重，检查同参考/曝光矛盾，再反复剪去不足10个训练参考的物理组和不足两个物理组的参考，确定完整连通分量。NSC object ID用于参考归并索引，不作为待测恒星盲关联真值。

每个分量联合求解星系静止位置及组常量。SDSS组为run/camcol，NSC组为实际exposure；不同CCD和field不另拟合新高阶项。采用float64二维Schur解析消去星系位置，矩阵自由共轭梯度解完整组图；紧凑整数索引和计算分块不产生局部独立零点。内部临时pin只帮助数值反演；发布gauge为剪枝后、SE筛选前同一NSC组集合的point中位。48次按物理参考对象的指数权重Bayesian bootstrap冻结最终IRLS，同一对象整条测量共权；draw先减各组均值，再减同一NSC集合公共中位模式。

参考IRLS为六次权重更新后一次最终point求解；point与声明权重一致。每个完整分量保留全部有解组、unfiltered快照、gauge集合SHA及48同步draw。局部应用门槛为实际检测处逆投影后的两轴参考SE均≤12mas，不是用整个长run/camcol的单一图平面SE筛除。图平面SE与实际位置的native SE均留作诊断。

## 位置、拟合与协方差

原生每轴发布误差与50mas底噪只合成一次：`sigma = hypot(published_sigma,50mas)`。原生两轴当前采用无相关近似，完整前向Jacobian得到`C_plane=A C_sky Aᵀ`，不能丢掉投影产生的交叉项。50mas是条件误差模型，不是已测得的独立夜或全空间系统误差。

源在完整参考图切平面拟合四参数直线、参考历元J2015.5。二维GLS以完整协方差计算Mahalanobis残差，稳健权重`min(1,6/(4+d²))`，八次求解中最后一次不再更新权重。当前独立项是冻结权重的`C/w`条件解释，不声称完整稳健频率学误差。

公共参考项先将同一分量的48次组扰动经过每源影响矩阵同步合成，再取协方差。标准ICRS输出对位置与速度一起使用完整4参数逆投影Jacobian，包括位置扰动对速度的导数；状态顺序为局部东位置、mu_alpha*、局部北位置、mu_delta。位置单位mas、速度mas/yr，中心RA/Dec另存为度。完整4×4含位置—速度交叉项；公共draw不再当原生误差重新前向投影。群体均值先合成同步draw，不能把公共误差按源数开平方缩小；不同完整参考分量分别合成协方差。

条件协方差未认证同夜相关、源类相关色差、残余局部零点或星系选择污染。全域源保留这些未认证标志。当前不向普通源拟合输入Gaia自行或视差，也未新增自由视差项；近距离/高自行及非线性运动不属于已认证适用范围。
