# 实验 A v0.3 · 普通源自行精度

从 `b92912c` 建立 `experiment-a-v0.3-precision`，只复用经校验的 v0.2 输入。原始、逐检测、逐源和校准缓存留在 NERSC。高自行关联沿用已发布的 v0.2 证据。先检验目录级精度，再决定是否需要图像级天测。

| 步骤 | 可核验证据 |
| --- | --- |
| 四区亮源基线 | 同源复核 214 颗的官方 NSC、NSC 重拟合、一次 SDSS、全部 SDSS，报告有效选择、观测组、时间杠杆和误差覆盖 |
| Xiao2025 地基产品 | 从真实成品识别 PM_SOURCE，按 Appendix A 保留 DESI 地基自行行，报告与 NSC 的唯一匹配及各退出数量 |
| 赤道公共零点 | 静止参考星系按对象分开训练和留出，验证星不参与；M2/M3 同对象同检测，输出支持率、偏差、NMAD、绝对误差和归一化覆盖 |
| 颜色及 DCR | 固定 M3 支持集，依次测试每仪器/波段的残余颜色和视差角方向项；按新参考对象和观测组检验，检查与时间的退化 |
| 暗端验证 | 用统一参考 r 星等分为 <20、20–21、21–22、22–23，分别报告 QSO、光度选取的星团成员及整年留出 |
| 决策 | 两项发表基准的暗端精度改善至少 15%，初轮零点每轴约 0.5 mas/yr，并核对异常尾和有效覆盖。剩余误差关联 seeing、SNR、混叠或像面位置后再选择 PSF 质心对照 |

赤道区 v0.2 北向全 SDSS 偏差 −4.40 mas/yr，NMAD 0.57 mas/yr。首轮检验能否用独立参考将偏差拉近零并保留小散布。若不改善，优先量化参考对象、波段及观测组的有效覆盖，再决定是否扩展校准区。


## 当前状态与下一步

- 四区 214 颗亮源基线复现完成。M3 在赤道、北天和拥挤区有共同检测对照，Pal 5 未达到参考覆盖门槛。赤道、北天仍有轴未达到 0.5 mas/yr。
- M4、M5 有独立对象与观测组检验。赤道北向散布下降，但偏差和跨巡天留出表现不足以采用。M3 为后续基线。
- 暗端先用五个 NSC r 留出曝光及 6 个光谱 QSO。21–23 等的留出位置收益未超过对象重采样不确定度。需补独立暗星团成员、观测覆盖与竞争匹配审计。
- Xiao2025 ScienceDB V3 已核验首部及实际来源标记。赤道试取的 4 个像素均超时，发表产品切片仍需完整通过边界检查；远程下载失败时，可在 Slurm 上向 `deep_pm.legacy_subset` 提供已验证的完整 FITS。三产品共同样本验收要求不变。
- 在第二个高参考密度测试区继续 A，优先核验按 frame/CCD 的残差、按观测夜共享误差与暗对象的对照覆盖。重新度量两发布产品和零点，达到本页目标才扩大目录。待 seeing、SNR、混叠或像面位置关联在独立场复现后再选图像实验曝光。
