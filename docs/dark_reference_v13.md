# 暗恒星独立参照的适用范围

本轮r≥21不使用Gaia自行验收或选模。光谱QSO提供静止源绝对运动检验，整年留出提供目标未参与训练的条件位置检验，两者不能合并宣称暗恒星真实自行已验证。

| 核验资料 | 数据依赖和覆盖 | 本轮用途 |
|---|---|---|
| GPS1（Tian等2017） | 官方说明整合Gaia DR1、PS1、SDSS及2MASS，典型深度r约20 | 与本研究共享SDSS且不覆盖主要21–23档，不能当主要暗端独立真值；没有以它替代暗Gaia限制 |
| HST ACS–Subaru HSC COSMOS（Faisst等2022） | 11年两历元，11,519个i=19–25点状源；文中还讨论太阳反射运动修正 | COSMOS专用足迹不与本轮五个登记窗口相交；不能为当前面积提供逐源验证。未来单独场需取得原始观测运动、历元及误差，不能直接用扣太阳反射后的量比较 |
| 当前NERSC研究输入 | 已成功取得SDSS/NSC、光谱QSO及Xiao DESI；没有成功取得并核验覆盖这些新窗口的独立深暗恒星长基线表 | 保存这一缺项，不标成零误差或零污染；以训练全程隔离的整年位置和独立NSC夜差分作为有限证据 |

该清单是本轮已核验候选，不能推断不存在其他可用资料，也不是完整文献普查。不因此扩大到新深场取数或启动图像重处理。整年位置匹配须报告门限、训练分母、芯片覆盖机会、唯一性和扰动对照；门限内残差与误差覆盖具有条件选择，不能用来声称无条件正确率。

资料核验：2026-11-18。[GPS1官方数据说明](https://dc.g-vo.org/gps1/q/cone/info)、[GPS1 CDS发布说明](https://cdsarc.cds.unistra.fr/viz-bin/ReadMe/I/343?format=html&tex=true)、[COSMOS原论文](https://arxiv.org/abs/2203.05658)、[作者机构发布记录](https://authors.library.caltech.edu/records/8qtqw-50k24)。
