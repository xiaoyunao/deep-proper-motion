## 分阶段和复现

科研入口参数及私有路径保存在个人配置和阶段回执，公开只给符号路径。候选：`python -m deep_pm.usability_candidate REGISTRATION CANDIDATE_REGISTRATION OUTPUT --workers 2`；独立质量读出：`python -m deep_pm.usability_candidate_readout REGISTRATION TRIAL OUTPUT --workers 2`。旧CSV原行／身份映射保存在候选核心的私有纠正映射层，原追踪及归档不覆盖。

新生产派发以物理参考图划分归属／覆盖分区，随后单节点累计，最后单节点盲质量；分别签名和依赖。原有science作业账本不会自动重复派发。`production_science --phase partitions --graph GRAPH`可核验已完成分区，仅未缓存的覆盖提取需要真实window_flist参数；`--phase merge`只接受完整签名分区，不默默新算。默认all入口保留。新调度的尾部最大规划3节点小时（2×60min、1×30min、1×30min），不在单线程尾部保留第二节点。

真实统计基准40,001 QSO／800draw：原43.102s／3419.14MiB，分块26.493s／1000.73MiB；输出SHA7f090ad23e6a96686d045ae0692867b8fc0d090fcf2808566f003ec7d18c044f完全相同。签名缓存0.02883s。原拟合内核、样本、draw数、随机序列及分位数未改。

测试环境采用OMP／OPENBLAS／MKL／VECLIB单线程；219项通过。初次本机未限制原生线程时在sklearn邻域实现段错误，未当成功；重复运行记录保留。科学任务使用Linux Slurm，不在登录节点拟合。

最终15作业资源折算0.04262 CPU节点小时，其中性能／复用核验0.00175；10／2预算未超，末次squeue为空。任务PScratch快照2.370GiB／1701文件，不是全过程存储峰值。详细[sacct账本](../results/summary/v20_resource_summary.json)，最终账务以Iris为准。
