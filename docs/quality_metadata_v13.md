# 正式产品所需的误差与参考系元数据

本轮仍是实验研究。以下区分实际已保存字段与正式产品尚需完成的质量信息，不把形式误差自动解释为空间零点认证。

| 层级 | 实际已保存 | 正式产品的要求及当前限制 |
|---|---|---|
| 源坐标与运动 | J2015.5 ICRS位置、每源pmra/pmdec、4×4协方差、原切平面量与投影中心 | 输出标准ICRS及明确状态顺序；原目录两轴位置协方差缺失的近似需要说明 |
| 独立与公共误差 | 私有标准表分别保留独立和参考bootstrap切平面协方差；完整Jacobian | 不能把公共零点项随源数开平方缩小；跨独立图公共协方差尚未求解 |
| 拟合支持 | 关联／使用检测数、SDSS run数、时基、校准组数、稳健降权数、组最大斜率份额、删组位移 | `independent_groups`是校准组数，非独立季数；正式输出须明确UTC18夜与实际观测季支持 |
| 可追溯性 | 源级检测ID及实际曝光／夜、输入／参考／配置SHA、源码commit及Slurm回执（仅远端） | 不能从参考图外推无支持曝光；跨区需共用物理组标识和统一参考历元归属 |
| 选择与形态 | r分档、保留的原标志计数、W0质量漏斗 | C0没有增加标志位硬切；形态非有限／域外值和参考源重叠需单列标志，W0并非已验证恒星全集；宽松／严格对象与盲目录、已知位置控制的适用范围须分开 |
| 空间参考系 | 每窗图连通分量、组支持、NSIDE128诊断、留出星系和QSO汇总 | 源需绑定分量／规范；区域需声明零点认证尺度、样本数、两轴值／区间和未认证原因 |
| 模型与使用等级 | C0/W0 r-only；C1/C1b及误差／多波段试验负结果 | 每轴0.5mas/yr仅为高精度目标；未认证区不能使用同一高精度标签。新增源零点未过关，不并入正式产品 |

若新增独立区只支持相对NSC的精度改善，而普通区相对Xiao没有稳定收益、跨图系统项仍不足，应该保留研究版本和条件质量分级，不因处理面积足够就启动统一高精度全覆盖生产。最终判定需在预登记独立测试之后作出。
