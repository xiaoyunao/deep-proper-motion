# 实验 A v0.1 · SDSS+NSC 目录级多历元自行探针

**2026-11-16**

公开检测已经足够检验联接失败发生在哪一环。在 Stripe 82 的三颗确认源上，正确组合都进入了候选表。第一版因竞争连通分量过大而整体跳过，在独立探针上低于简单方法。开发区增加求解预算后找回两颗。平移对照也能形成跨巡天轨迹。Pal 5 的 20 颗配对源显示早期 SDSS 有实质收益，加入重复扫描后仅东向散布进一步下降。现在应继续实验 A，解决冲突与置信度约束。证据还不足以进入实验 B。

## 样本与口径

先用中心半径 0.02°、外围 halo 0.017° 的四个小锥区探查。该尺度小于预定的 NSIDE 128 smoke test。Stripe 82 的单锥区已取回超过 3 万条 NSC 测量且形成超大冲突分量，故先保留小规模探针，未下载 10–30 平方度。关联输入统一使用已确定时间、坐标误差 ≤150 mas 和已知原生波段星等 ≤20.5 的检测。保留形态不稳定检测。核心和 halo 一起搜索，在 2015.5 历元上确定验证对象的核心归属。

SDSS 用 DR17 `PhotoObjAll` 的 run 内唯一检测，保留各物理 run，Stripe 82 专用 DR7 目录仍待加入。NSC 使用 DR2 `meas`。在开发区锥内抽八个曝光、15 个 CCD 做路线对照，两路各取得同一批 **134 条**单曝光检测。该检查未出现路线独有测量，不能约束全部曝光及高运动源的索引漏检。北天在实际元数据中包含 KPNO 4m Mosaic3 和 Bok 90Prime（NSC 标记 k4m、ksb），未核实与 Legacy Surveys DR11 的逐曝光重合关系。四区合计核心面积约 **0.0050 deg²**，标准化 **271,636** 条含 halo 的真实检测，其中 **57,723** 条用于三法共同比较，得到 **25** 颗核心内 Gaia 跨巡天验证源。原始表和逐源结果只留在 NERSC。

盲测程序单独读取 Gaia DR3，自行和传播位置不进入关联。NSC 位置由 Gaia DR2 标定，检测级标签是可用的外部参考，天测标尺存在共用成分。真值要求核心内跨 SDSS/NSC 的可靠 Gaia 标签，恢复要求同一轨迹找回至少 80% 的可靠标签。真实跨度、通带、核心/halo 和误差筛选数量可查 [汇总](../results/summary)。

开发区的 0/2 与 2/2，对应 Wilson 95% 区间分别为 0–65.8% 和 34.2–100%。留出区只有一颗亮星，0/1 的上界为 79.3%。光凭数百条来自同一颗星的标签不能将污染区间压到 1%。未标注的成员不进入错配分子。北天的完整种子搜索由 70 对增加至 499 对，恢复依然为 2/2。北天弱约束样本也体现了简单方法在典型低自行源上的竞争力。本轮最高非空 Gaia 自行区间为 50–100 mas/yr，缺少 200 mas/yr 以上的真实验证对象。Pal 5 的运动法为 0/20（Wilson 95% 上界 16.1%），两基准均为 20/20（下界 83.9%）。拥挤区产生 25,826 条候选，关联耗时约 65 秒，峰值常驻内存约 350 MiB。对 Pal 5 的 20 个漏检对象，候选审计同样找到了达到恢复门槛的候选，但它们全部落入同一超预算分量。

开发区和留出区分别生成 2,220 和 1,084 条候选。被漏掉的三颗星各有覆盖 100% 可靠标签的跨巡天候选。竞争分量包含 2,128 或 601 条轨迹，超过 100 条的冻结上限。用完全相同的候选在开发区把上限提高到 3,000，求解约 0.69 秒，没有未解分量，恢复 **2/2**，与 NSC-like 打平。该改动没有回填留出结果，仍缺独立重测和高自行样本。这一消融把目前的首要失败定位到了冲突分量处置。

整年留出在生成任何候选之前移除整年检测。开发区 2017 年的固定半径和 NSC-like 分别确认 128/128、125/125 次有真值的预测，位置偏差中位数约 23 mas。留出天区 2014 年两基准均为 57/57，约 28 mas。运动法在此口径下两区均无可评估预测。把 SDSS 整体向东平移 18″ 后，RA 0° 裁剪样本的运动法仍给出 3 条跨巡天轨迹，与原坐标中的 3 条相同，两基准均从 1 条降到 0 条。这是单一位移的负对照，不能直接转作污染率。

注入使用开发区真实背景、真实时间、曝光内实测点构成的内缩凸包、邻近检测误差和缺测抽样。主试验各自行档 3 次，跨两巡天且至少三组实际获准的注入只有 200 mas/yr 的 1 条、2000 mas/yr 的 2 条。三种方法均未恢复这些轨迹。10000 mas/yr 压力测试有效 1 条，三法均未恢复。其余自行档在这一足迹代理中没有有效分母。样本极小、缺测模型简化，需要真实芯片/field 掩膜及更宽查询区才能估计注入召回。该结果保留为压力探针，不能支持高自行真实性或污染水平的定量结论。

另行按 Gaia 质量和自行选了一个 Stripe 82 挑战探针。候选来自 1° 搜索范围内、200–2000 mas/yr 的质量合格源，以粗四舍五入坐标建立固定锥区。该区与代表性验证分开。统计截稿时 Perlmutter 的普通 CPU 与共享分区均为 down，挑战作业仍处于 `PartitionDown` 队列状态，尚无检测关联结果。

## H2 · 一次早期 SDSS 的收益取决于原有基线

固定由 Gaia 标签确认的同一组对象，以 NSC-only、加一次最早合格 SDSS、加全部扫描作三路配对。北天仅一条 SDSS run，基线中位数由 **1.36 年变为 13.17 年**。两颗星的东/北向残差中位数由 (−6.66, +16.57) 变为 (+0.59, −2.83) mas/yr，超过 20 mas/yr 的对象由 1/2 变为 0/2。前者的 Wilson 95% 区间为 9.5–90.5%，后者为 0–65.8%。这里的改善来自延长基线。

两个赤道探针有较密的 NSC 时间采样。NSC 基线约 6.5–6.9 年，加 SDSS 后约 20.5–20.9 年。三颗星的残差并未一致改善。RA 0° 唯一配对源的两分量残差由 (−1.50, +1.66) 变成 (+0.47, +2.06)，加入全部扫描后为 (+2.08, +4.42) mas/yr。早期扫描增加杠杆，也可能加重巡天间或共享观测误差。样本不足以评估总体散布，更不足以确认 SDSS 重复次数的独立收益。

Pal 5 的 20 颗配对源基线中位数由 5.93 年增至 19.96 年。东/北向 NMAD 分别从 **2.12/2.37** 降至 **1.20/0.85 mas/yr**，加入全部 SDSS 后为 **0.92/1.34 mas/yr**。东向偏差中位数从 −3.74 变为 −0.52、−0.26 mas/yr，北向从 +0.17 变为 +0.04、−1.16 mas/yr。在这个样本中，一次早期 SDSS 已提供主要改善。重复观测进一步改善东向指标，北向表现回落。

按整夜重采样显示，北天加入 SDSS 后，两颗星的夜级误差与形式误差之比中位数约为 1.3–3.3。该估计对一条早期 run 是否被抽到敏感，说明单用拟合协方差不足以量化杠杆效应与可靠性。两个赤道区样本更密，但配对源更少。 [整夜重采样](../results/summary/north_night_bootstrap_summary.json)

## H3 · 瓶颈已可定位，位置误差来源尚未分清

波段、原生星等和 airmass 已作首轮目录残差诊断。样本由少量独立控制源组成，其中 Pal 5 样本仍集中在单一拥挤环境。即使某波段有数百次检测，也难以从这批源区分颜色项、曝光共享偏移、时间采样、混叠和视差。没有足够的独立参考星系和检验星系执行交叉验证校正，未增加 DCR 或局部零点拟合。未开展视差几何拟合、目标切图、混叠逐图审计或已发布 NSC 自行的精度比较。已核对的 NSC object ID 统计仅用于发现已有对象归并中的潜在拆分和错误合并。

对无可靠 Gaia 自行的暗源，理论上的整年留出路径已在真实检测上执行，但本轮成功预测来自有标签的亮源。对暗源还没有经校准的可靠性证据。最有价值的下一阶段是 **扩展 A 的验证能力**。冻结新的冲突求解规则，查清平移后仍可形成轨迹的条件，建立独立高自行挑战样本和有代表性的按天区留出。只有稳健关联仍受位置系统误差限制时，才用相应曝光设计 B。
