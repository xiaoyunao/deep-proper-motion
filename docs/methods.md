# 实验 A 方法

固定半径法以时间顺序扫描检测，使用切平面 1″ 邻域建组，每物理曝光最多取一项。NSC-like 以 DBSCAN（0.45″、min_samples=3）确定中心，之后用 1″ 合并剩余测量，继续为孤立成员建组。同一输入、天测底噪和拟合用于比较。该基准参考论文对 DBSCAN 和剩余检测顺序归并的定义。 [NSC DR2 论文](https://arxiv.org/html/2011.08868)

运动法先保留静态暂定组。轨迹种子从相隔至少 0.6 年的独立时间组生成。搜索半径结合真实时间差、最大速度、两端误差和模型余量。每位置组每观测季使用误差最小的种子代表，邻域验证仍可使用全体检测并可重新占用暂定组中的任意检测。完整种子模式可配置。由于种子代表可能丢失移动源或把两源混在一起，代表模式的物理搜索范围与实际召回必须分别测量。时间组按连续测量之间 100 天的间隔划分。

候选按种子误差外推、同曝光约束和稳健拟合验证。评分包含独立时间组数、成员数、拟合残差和局部检测密度。它是排序分数。冲突图连通分量内做二元最大权集合打包，约束每检测只分配一次。超出分量预算或求解时间的组保持未解，候选表留在 Scratch。两时间组、相近的竞争轨迹及未匹配状态分别保留。当前未加入软测光似然、严格混叠分类或可校准的偶然轨迹概率。

每轨迹同时算加权线性和迭代稳健解，输出参考历元位置、自行、独立误差假定下的协方差、跨度、权重及拟合诊断。原始位置被保留。区域统计中的主要检验包括盲 Gaia 标签、整年预测与平移错配。误差相关性和局部参考框架见结果限制。 [未知运动的关联方法](https://doi.org/10.1088/0004-637X/719/1/59)

现有圆形探针用 0.017° halo。HEALPix 几何辅助函数支持 NSIDE=128、参考历元归属及跨块冲突去重。边界和共享检测单元测试不代表已规模化执行。完整 HEALPix 扫描和测量协方差在大天区切平面的传播仍待完成。
