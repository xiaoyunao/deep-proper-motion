# 广域科研生产与质量回执

从 v1.6 `992c9f1` 冻结数学和质量选择。SDSS 的独立物理 run 使用发布 r 质心，查找输入重复须按真实检测身份。NSC 对象仅作检索索引。NSC 全波段取数、星系 C0、50 mas 对角权重、同步 bootstrap、J2015.5 ICRS 状态及 4×4 条件协方差用原验证流程。冻结 C 和北二区是生产对照，扩参考图时旧结果独立留存。

## 数据和参考

- 旧缓存分片用 `nsc_allband_inputs` 补齐。原 r 输入、目标几何与回执绑定，逐检测检查旧 SDSS r 和 NSC 的位置、误差、时标及 photometry。原始私有文件只留 PScratch。
- 新天区使用 `independent_batch` 生成分片。如总配置包含 `nsc_all_objects = true`，则 `exposure_inputs` 直接获取可检索的全部 NSC 对象测量，避免下载两遍再取消 r 索引限制。数据版本、COUNT 及备份查询仍以回执核验。
- 原参考身份/split 与固定质心保留。共享组被发现跨窗口时，`joint_reference` 重投影实际参考，`continuous_reference solve --separate-components` 一次联合求解。记原投影、共同图支持数、分量和拒绝数。W0 的原生位置误差切平面近似保持不变。每个生产分片保留实际图 SHA 与拟合时使用的参考分量。
- 初始 A/B 原图共享 1 个保留组，北一／北三共享 131 个，北一／北二区 8 个，北三／北二区 3 个。北二区重放可用于保持新一版账本一致，面积与原北二区并集只计一次。现有 C 区冻结对照单独核对物理组重叠。

## 科学产品

广域拟合通过 `nsc_science_catalogue`，归属按拟合 J2015.5 的位置。归属变更用签名索引保留原状态、协方差、成员及回执。HEALPix NSIDE=128 用于存储索引与质量分区；参考求解覆盖实际相连的校准观测。每批记录重复检查、跨核物理成员共享和未获参考支持的区。

新增质量标识只在广域配置置 `production_quality_tags = true` 后启用。无 NSC r 锚点独立列出。某个物理组在任一轴占至少 80% 的条件斜率信息则标高杠杆。各核心参加投票的参考分量计数保留，用于说明同一核心可能有少用参考数据。原未知空间系统、夜相关与暗星身份质量标志继续保留。

`nsc_science_summary` 按相同光谱源分别给物理 r 和全 NSC，外部再比较 Xiao2025 的 DESI 来源及官方 DR2。绝对 P68、NMAD、误差覆盖、两轴零点、来源类和时基保留。位置唯一匹配提供条件身份信息。独立年位置使用全部 band 先隔离测试年。暗端 Gaia 自行退出验收。

名义面积、带参考支持的几何时基及实际科研解覆盖分列。`nsc_transfer_footprint` 按实际每核心参考分量读 CCD 多边形、原生 SDSS 扫描和真实时刻。几何条件沿用至少一次 SDSS、两次 NSC、NSC 跨度 0.60 年以上、联合跨度 5 年以上。几何机会面积独立于逐源深度、源提取、配对和正式空间零点认证。

全部作业在 Slurm CPU 节点运行。原始、逐源、私人星系和光谱证据保持在 PScratch。每批从明确允许列表同步聚合统计、图和研究记录。

新天区输入与参考提取入口为 `scripts/wide-v17-inputs.sh`。传入登记选区、同一几何配置、已核验光谱缓存、SDSS SAS 与 Xiao FITS，并使用 Slurm 计算节点。取数与参考提取单独留回执。第二批选区先冻结原生几何，详见 [登记统计](../results/summary/v17_wide_selection_summary.json)。

对旧原始 NSC 分片，`nsc_allband_inputs --reuse-r-archive` 可核验旧签名后只取原 r 对象谓词的补集。三个真实核心与完整重新取数逐列重放，通过同一检测身份、数据值、对象标签和官方外部字段核验。只有具有相同已签名几何、halo 和旧原生 COUNT join 的缓存使用补集，其余仍走完整取数。 [实测重放](../results/summary/v17_complement_replay_summary.json)

缓存窗口的共同参考回执确认北、赤道和冻结 C 图保留的物理组彼此不重叠。每个状态的参考身份应读 `reference_model_sha256` 与图内 `reference_component` 两个字段。数字分量标签在不同图中可重复。新区域的重叠先按 CCD 和扫描几何预查，再按实际星系测量联合组拟合。 [已求解缓存图](../results/summary/v17_cached_shared_reference_summary.json) · [广域几何组预查](../results/summary/v17_wide_projection_preview_summary.json)

边界以实际登记的半开核心并集及拟合 J2015.5 位置为准。外移至另一登记核心的行只转移逻辑归属。真正位于并集外的行仍作为签名原拟合保存，归属索引记空值，公开区域统计及区域读取不计入这些行。坐标、自行、协方差和物理成员保持不变。区域内的共享检测冲突与重复坐标仍需修复。

读取冻结 v1.2 星系参考摘要时，若历史摘要省略了投影中心，使用 v1.2 已知的默认中心，并检查原归档切平面坐标与重新投影的差不超过 0.0001 mas。通过检查后才能把相同星系、原生误差和训练／留出身份带入共同图。旧参考回执与失败尝试独立保留。

各图完成后按签名拟合回执、共同参考图和最终归属合并。区域共享的物理观测组在完整参考账本中只能出现一次。公开读出核对两端 SHA，并将少于五个对象的观测组自行统计收敛为计数。原签名结果及逐源索引留在 PScratch。

预汇总在写出科学统计和光谱池以后会报告尚未解决的 J2015.5 边界归属。续跑核对参考图、逐块拟合回执及两份产物的 SHA，再为无共享检测冲突、无重复位置的分区建立最终归属索引。最终科学回执要求三类冲突均为零。三类源的观测夜、季、时间杠杆、波段和形式误差统计从最终归属回执读取。少于五个源的核心分层只公开计数。

使用 `python -m deep_pm.nsc_wide_figures SCIENCE_JSON SPATIAL_PNG --conditions-output CONDITIONS_PNG` 从去标识科学汇总生成核心空间图及观测条件图。观测条件图按实际 run、NSC 时基、夜数和仪器组合给相同光谱对象四路比较。核心空间图上的五对象下限和观测条件图上的百对象下限用于显示。独立空间零点和误差资格仍读取验证统计与质量标志。

续跑汇总读取原来的源级观测质量标志，将科研解分为三组。r 锚点中少于三个 NSC 季或任一轴由单个物理组提供至少 80% 斜率信息的对象归为观测支持受限，其余 r 锚点归为观测抽样充分。非 r 锚点单列。每组报告源数和含该组科研解的核心面积，同一核心可能有多类源。独立光谱、空间零点和误差覆盖沿用各自验证证据。
