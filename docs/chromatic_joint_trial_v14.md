# v1.4 最小共同色项试验预登记

触发证据：北一原训练/留出星系的g残余诊断，颜色模型相对常数模型在1494个留出物理参考上P68改善4.16%，对象区间1.36%–6.09%；B区未稳定复现。这里不把对象区间当曝光级独立证据，也不因QSO零点选择系数。

## 唯一新增项与固定对照

在既有N1/N3共同参考的主连通分量0中，联合求静止参考位置、原物理组零点，以及仅DECam g的一项二维残余颜色系数。特征为`I(c4d,g) × (SDSS PSF g-i - 1.2)`；SDSS r与其他band没有额外颜色系数。它是经验剩余色项，不称为已识别或完整的DCR模型。分量1保留原C0规范与抽样，不用色项假装连接其绝对零点。

全部原参考检测、身份、坐标/原生误差和训练/留出保留。只补读取缓存中相同物理SDSS检测的颜色与核验的曝光instrument/band。物理参考的颜色来自其唯一SDSS检测的全局中位数；缺颜色不删参考，特征置零并计数，代表未校准域。源级缺颜色也必须单独记录，不通过缺色删掉暗源来获得漂亮结果。

C0/W0、50mas、四参数、J2015.5不变。单独色项与曝光常数/参考源常数的线性退化由显式秩检验拒绝；不能另添一个不可辨识的band常数。

## 公共误差

零点与色项使用同一物理参考Bayesian bootstrap抽样；应用到每条目标检测时，组偏移与色项样本先相加，再传播到完整4×4参数协方差。不能把两者误差当独立平方和，也不能把跨源公共项按源数缩小。模型以独立文件名保存，普通C0读取器明确拒绝忽略色项。

本试验的颜色作为固定代理，尚未传播源和参考的颜色测量误差、相应衰减偏差；若不能证明这些限制对目标精度/覆盖足够小，即使点估计有收益也不冻结正式模型。原W0未建模的原生共模/混叠同样保留限制。

## 评估与停止

先比较相同留出星系的位置；再用原固定QSO和相同r/all成员比较C0 r、C0 all、色项模型r、色项模型all，以及严格共同NSC/Xiao。北一控制核、预登记90Prime核与北三普通核分别报告，不把这些已读旧天区称从未打开的新盲区。QSO不训练任何系数。

只有QSO有收益且零点/尾部不恶化，才进一步解释其使用范围；独立年份对照仍须在冻结目标身份上对相同物理观测应用各模型校准，并保留训练—留出公共协方差。若只改善参考星系、不改善普通恒星/QSO，判为不能直接从星系色项迁移，不继续堆叠色项或按QSO调零点。

采用和约10×10度完整多band目录仍受PLAN第8步约束；本试验本身不授权正式生产。

## 冻结盲新增源的后验零点检查

同一色项模型也在原年度训练目录的全部固定身份／检测上重拟合，保持未获得测试年重现的候选在分母中。只有之后用原光谱位置唯一对应和逐成员位置标签分层，报告C0与色项的两轴零点、P68、未知／竞争成员及有限样本区间；不按色项结果选身份，不让QSO参与系数训练。原测试年位置和匹配不改。该项用于检验新增源偏差是否实际缓解，仍不自动成为采用目录。
