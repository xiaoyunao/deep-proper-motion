# v0.6 位置、时间和误差模型审计

- SDSS DR17 发布 `RA/DEC` 采用 J2000 平均参考坐标，天测流水线已施加逐 frame 的位置及颜色变换。原有节目将 `RAERR` 按东西向角距离使用，`DECERR` 按南北向角距离使用，均从角秒变为 mas；避免再次乘 `cos(dec)`。只接受 r 到参考位置的 `OFFSETRA/OFFSETDEC` 均为零的记录，时间取 `TAI[r]`（MJD 从起点累计的 TAI 秒）。官方文档区分 `photoObj` 的 `objc_rowcErr/objc_colcErr` 像素质心误差和 `photoField` 的 `muErr/nuErr` 大圆坐标系 frame 标定误差。实验未逐条重建 `RAERR` 的误差预算，因此不在它之上额外叠加 `photoField` 分量。 [SDSS 天测说明](https://www.sdss4.org/dr17/algorithms/astrometry/) · [photoObj 数据模型](https://data.sdss.org/datamodel/files/BOSS_PHOTOOBJ/RERUN/RUN/CAMCOL/photoObj.html)
- NSC DR2 的 `meas.ra/dec` 是发布 J2000 位置。DR2 逐曝光用 Gaia DR2 位置和自行标定至观测时刻。已检查的官方代码把角秒质心误差与天测拟合 RMS 按平方和合并，组合代码用相应的东向角距离约定解释 `RAERR`，发布表说明仅称其为 RA 不确定度。此源码提交是当前可追溯参考，发布版本的证据以 DR2 论文和档案数据为准。采用已缓存的 NSC MJD UTC 转 TT、SDSS TAI 转 TT，拟合用 365.25 日的 Julian 年。 [发布测量字段](https://datalab.noirlab.edu/data-explorer?showTable=nsc_dr2.meas) · [NSC DR2 §III](https://arxiv.org/html/2011.08868) · [源码 7c0756e 的标定](https://github.com/astro-datalab/nsc/blob/7c0756eea30b7a3afcab0e204310ee39e1c5dabc/python/nsc/calibrate.py#L1631-L1643) · [RAERR 的组合运算](https://github.com/astro-datalab/nsc/blob/7c0756eea30b7a3afcab0e204310ee39e1c5dabc/python/nsc/nsc_instcal_combine.py#L424-L435)
- SDSS 平均坐标和 NSC Gaia 定标坐标在本区域实验按同一固定参考架处理，场内 M3 对静止参考差作经验校正。没有独立识别两套发布位置的逐项残余岁差、章动或周年光行差；直接转成观测日坐标或由本项目重新减周年光行差会改变发布参考架。L5 处理不同物理量即源的周年视差，用 TT 计算地球质心到太阳系质心的矢量，求同一场切平面的两轴因子。对近星的真值标注可用 Gaia 视差预测；L5 拟合只见目录位置和时间，视差允许取负。校验的是有效相位与斜率收益，单一亮星自由视差的形式误差不能用于外部校准暗星。 [Gaia 天测模型](https://doi.org/10.1051/0004-6361/201628714) · [GPS1](https://arxiv.org/abs/1703.06278)
- 旗标对照 Q 使用 NSC 当前记录的 SExtractor 4–128 位和 SDSS 现有汇总旗标的 EDGE、SATURATED 位及 `NCHILD`，其选择函数由同源退出量体现。它未使用尚不完整的逐 frame BAD_ASTROM 标志。在不破坏双巡天覆盖和基线时，对最多两个可删高杠杆组作预测检验，并至多移除一个所有可用点均超过 5σ 的组。共同零点可能小于单源残差，删组不确定度包括拟合误差的独立近似，存在共用校准时作为敏感度诊断。按 SDSS 物理 run 和 NSC UTC 正午分组，后者近似美洲台址的光学观测夜；同组的多检测不等于多独立时间锚点。 [SDSS 质量位](https://www.sdss4.org/dr17/algorithms/photo_flags_recommend/) · [SExtractor FLAGS](https://sextractor.readthedocs.io/en/stable/Flagging.html)
- W0 采用已发布的每轴形式误差与统一 50 mas 底噪。W1 在固定 M3 坐标上由训练星系的同仪器/波段、不重叠的跨扫描（NSC 跨夜）对做差；以 Student 似然估计形式误差比例与额外底噪，各场独立拟合，稀疏类别回退 W0。W2 将 W1 边际方差的一部分分给同一 run 或同一夜的公共误差。公共项由训练星系的组中位残差散布估计，用于灵敏度试验。三者都传播星系重采样的 M3 位置改正误差。训练星系参数可跨源传播公共系统误差，留出星系、QSO、Gaia 分别检查归一化误差、零点和星源散布。
- 普通场面积覆盖以 DR17 的 rerun=301 字段原生 great-circle 边界作均匀球面抽样，合并同 run 相邻字段。源计数要求盲轨迹有 NSC r 锚点，r 使用 NSC 检测星等中位值；星等较暗时可用 SDSS 实测率低于几何覆盖率。Stripe 82 控制是历史光谱/校准选区的目录切片，几何仍基于 DR17 普通索引。全巡天累计成像面积 / 唯一面积为 31,637 / 14,555 ≈ 2.17；该比值不直接给出多次扫描的面积比例。专用 DR7 Stripe82 的 303 个独立 run 和 2 个 coadd 另计。 [DR17 成像统计](https://www.sdss4.org/dr17/scope) · [Stripe 82 说明](https://classic.sdss.org/legacy/stripe82.php)

用 Astropy 对六个场心和每场八个边缘方向做 FK5 J2000 → ICRS 数值对照，固定参考架合理性以局部变化评估。若假定一批坐标确实属于 FK5，场心转换量为 5.1–30.7 mas，场内边缘相对于场心的差分小于 0.34 mas。测量链路不额外施加此变换，因为发布 J2000 标签未独立证明 SDSS 数值属于严格的 FK5 实现。对固定坐标系之间的场内公共偏移，M3 本身提供位置零点约束。 [Astropy FK5](https://docs.astropy.org/en/stable/api/astropy.coordinates.FK5.html)
